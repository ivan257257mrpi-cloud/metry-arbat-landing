# Что заменить перед запуском

В коде такие места отмечены комментариями `ЗАГЛУШКА` (нужны данные) и `ПРОВЕРИТЬ` (данные есть, но их надо сверить).

## Доступы и файлы

| Что | Где заменить |
|---|---|
| Вебхук Битрикс24 (входящий, права «CRM») | `public/config.php` → `bitrix_webhook`. Пока он пустой, заявки пишутся в `leads.log` на сервере |
| API-ключ Яндекс Карт (JavaScript API) | `src/config.js` → `yandexMapsKey`. Пока ключа нет, показывается карта OpenStreetMap |
| PDF презентации | положить в `public/files/presentation.pdf` |
| Обложка презентации для попапа | `index.html`, блок `modal__cover` (сейчас это рендер фасада с надписью) |
| Текст политики обработки персональных данных | `public/policy.html` |
| Счётчик Яндекс Метрики | `index.html`, в `<head>` (цель `lead` уже отправляется после заявки) |

## Контент

1. **Документы по проекту**: сейчас стоит форма «Запросить документы». Если юристы разрешат открытую публикацию, её можно заменить списком PDF.
2. **Формат «Целый этаж»** скрыт до подтверждения, что этаж продаётся единым лотом.
3. **Фото коридора до реновации**: исходный файл был повреждён, стоит копия из документа правок (1536×2048).

## Проверить

- **Объекты на карте** — `src/places.js`. Спорт и аптеки пока условные точки, их нужно заменить реальными адресами.
- **Параметры этажей** во вкладках «Планировки по этажам» — сверить с менеджером.
- **Расстояния и время в пути** в блоке «Арбат, 4/3».
- **Условия покупки**: взнос 50%, рассрочка до 12 месяцев, удорожание, правила бронирования.
- **Технические показатели инженерии** (мощность, приток воздуха) на сайт не выводились, по ТЗ их публикуют только после сверки с инженерным проектом.
- **Доходность и окупаемость** (из презентации в Figma) по ТЗ не публикуются до утверждения финансовой модели.
- **Логотип** снят с макета в Figma в высоком разрешении (`media/brand/`). Если есть SVG из фирменного стиля, лучше заменить им.
