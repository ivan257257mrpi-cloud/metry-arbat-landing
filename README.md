# Лендинг бизнес-центра на Арбате, 4/3 — «МЕТРЫ для бизнеса»

Статичный одностраничный сайт: HTML, CSS и JS, сборка через Vite. Заявки отправляются в Битрикс24 через `send.php`.

## Команды

```bash
npm install        # один раз
npm run dev        # локальный просмотр: http://localhost:5173 (формы в этом режиме отправляются «понарошку»)
npm run build      # сборка в папку dist/
npm run images     # пересобрать картинки из media/ в public/img/ (если поменялись исходники)
npm run deploy     # собрать и выложить демо-версию на GitHub Pages (ветка gh-pages)
```

Демо-версия на GitHub Pages: формы там работают в демо-режиме (PHP на GitHub Pages не выполняется).

## Публикация на хостинге

1. Выполнить `npm run build`.
2. Залить **содержимое** папки `dist/` на хостинг с PHP 7.4+ и расширением cURL (Timeweb, REG.RU, Beget и т. п.).
3. Указать вебхук Битрикс24 в `config.php` на сервере.
4. Проверить, что `config.php` и `leads.log` не открываются из браузера. Их закрывает `.htaccess` (Apache). На nginx нужно закрыть эти файлы в конфиге сервера.

## Структура

- `index.html` — вся разметка и тексты страницы.
- `src/styles/main.css` — стили. Цвета, шрифты, радиусы и отступы описаны в `:root`.
- `src/main.js` — плавный скролл (Lenis), появление блоков (GSAP), шапка, меню.
- `src/sliders.js` — горизонтальные галереи (Swiper), вкладки галерей и планировок.
- `src/lightbox.js` — просмотр фото на весь экран.
- `src/modal.js` — попап, тексты для разных кнопок и автопоказ.
- `src/forms.js` — маска телефона, проверка полей, отправка, UTM-метки.
- `src/map.js`, `src/places.js` — карта окружения с фильтрами.
- `src/config.js` — ключ карты, координаты, путь к PDF, задержка попапа.
- `public/send.php`, `public/config.php` — обработчик заявок для Битрикс24.
- `scripts/images.mjs` — оптимизация изображений (WebP нескольких размеров).
- `scripts/pages-clean.mjs` — убирает PHP-файлы из демо-версии для GitHub Pages.
- `media/` — исходники изображений (в репозиторий не попадают):
  `renders/` рендеры, `before/` фото до реновации, `plans/` планировки, `arbat/` фото окружения, `brand/` логотип и иконка.
- `docs/` — ТЗ и документы с правками (в репозиторий не попадают).
